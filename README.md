# Ody Mencari Sekolah

Aplikasi web satu halaman untuk membandingkan pilihan sekolah berdasarkan kriteria berbobot, biaya, dan peringkat.

Buka `index.html` langsung di browser, atau aktifkan GitHub Pages untuk repo ini.

> Catatan: versi aslinya dibuat sebagai Claude Artifact dan menyimpan data lewat penyimpanan artifact. Di luar Claude, aplikasi berjalan dalam mode lokal — perubahan tidak tersimpan.
